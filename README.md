# Wildberries Sheets Data Sync (GAS Automation) 📊

Автоматизированный модуль интеграции Google Таблиц с официальным **Wildberries Content API v2** для пакетной выгрузки и синхронизации каталога.

---

### Ключевые результаты
* **Масштабируемость:** успешная пакетная выгрузка базы из **11 000+ товаров (SKU)** в Google Таблицу без падений по таймаутам платформы (пагинация с паузами под Rate Limits).
* **Курсорная пагинация:** стабильная загрузка больших массивов данных через API-курсор (`updatedAt`, `nmID`).
* **Защита строковых данных:** предотвращение потери лидирующих нулей в артикулах (`00xxx`) и защита длинных штрихкодов от сжатия в экспоненциальный формат (`1.2E+12`).
* **Мульти-аккаунт:** архитектура с поддержкой подключения и переключения между несколькими кабинетами селлера через верхнее меню Google Таблицы.

---

### 🛠 Стек
* Google Apps Script (JavaScript V8)
* Wildberries REST API (Content API v2)
* Google Sheets API

---

### 🔒 Безопасность
Все персональные токены доступа селлера и ссылки на рабочие таблицы удалены в целях конфиденциальности. Для демонстрации используется тестовая конфигурация `WB_CONFIG`.
